# Stack

В этой задаче запрещено пользоваться почти всей стандартной библиотекой C++, кроме операторов `new`/`delete`. В частности, запрещено использовать `std::vector`, `std::stack`, `std::string` и прочие классы. Динамическую память нужно выделять вручную, вместо `std::string` использовать строки в стиле Си, `struct` и функции. Разрешено пользоваться стандартной библиотекой Cи.

Вам нужно вручную реализовать структуру данных "стек". Этот стек будет хранить строки. Для его реализации рекомендуется (но необязательно) использовать идею [односвязного списка](https://ru.wikipedia.org/wiki/%D0%A1%D0%B2%D1%8F%D0%B7%D0%BD%D1%8B%D0%B9_%D1%81%D0%BF%D0%B8%D1%81%D0%BE%D0%BA). Стек может быть очень большим, поэтому вам нужно будет хранить его элементы в динамической памяти. В каждом элементе стека будет храниться строка. В вашей программе не должно быть UB и утечек памяти. Всю выделенную на элементы память надо корректно освобождать при их удалении из стека.

Реализуйте для стека следующие функции:
- `Push(stack, str)`: положить переданную строку `str` в конец стека `stack`;
- `Pop(stack)`: удалить из стека `stack` последний элемент;
- `Top(stack)`: вернуть значение последнего элемента стека `stack`, либо вернуть `nullptr`, если стек пуст;
- `Size(stack)`: вернуть количество элементов в стеке `stack`;
- `Clear(stack)`: опустошить стек `stack`.

Обратите внимание на файл [main.cpp](./play/main.cpp). Здесь вы можете написать собственный произвольный сценарий использования стека. Это может быть удобно для целей отладки и поиска ошибок. Для его запуска нужно собрать и запустить таргет `play_stack`.
